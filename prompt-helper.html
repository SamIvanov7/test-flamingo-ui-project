UI/UX Design

💡 Новое: Усилители промптов

Теперь вы можете усилить стандартные промпты с помощью проверенных структур! Просто:

  1. Раскройте нужный промпт
  2. Выберите один из усилителей под промптом
  3. Получите расширенную версию с дополнительными инструкциями
  4. Скопируйте усиленный промпт одним кликом

💡 Совет: Вы можете выбирать разные усилители для одного промпта, чтобы получить различные подходы к решению задачи. Каждый усилитель добавляет уникальную структуру и глубину.

Визуальные улучшения

1 UI Only Changes
⌄
Prompt
The app UI should be improved, **without changing any functionality**. - Keep all existing logic and state management as is. - **Visual Enhancements:** Update the styling of the dashboard page: use a modern card design for each project listing, improve the color scheme for better contrast, and increase padding for a cleaner layout. - Ensure these changes do **not break any functionality or data flow**. *Goal:* purely cosmetic improvements for a more polished look, with the app behaving exactly as before.
🚀 Усилители промпта
⚖️ Compare-Contrast-Integrate
👁️ Visualize-Describe-Explain
🔄 Iterate-Reflect-Improve
📊 Pros-Cons-Alternative
Когда использовать
Когда нужно улучшить внешний вид приложения без изменения функциональности. Подходит для полировки UI, настройки макетов или реализации конкретного стиля дизайна.
Как использовать
Четко укажите область изменений дизайна и подчеркните, что функциональность должна остаться неизменной. Укажите желаемый стиль (современный, минималистичный и т.д.).

Responsiveness / Адаптивность

1 Full Responsiveness
⌄
Prompt
Our app needs to be **fully responsive** across mobile, tablet, and desktop. - Follow a **mobile-first** strategy: prioritize the layout for small screens, then adjust for larger screens. - Use modern UI/UX best practices for responsive design. (For Tailwind CSS, use the standard breakpoints `sm, md, lg, xl` – no custom breakpoints unless necessary.) - Ensure every page (especially the dashboard and project detail pages) reflows properly on a small screen: elements should stack or resize as needed, text should remain readable, and no content should overflow off-screen. - **Do not change the core design or functionality**, just make sure it flexibly adapts to different screen sizes. After making changes, please double-check the layout at iPhone 12 dimensions and a typical desktop width.
Когда использовать
Когда макет приложения должен работать на разных устройствах или когда интерфейс ломается на мобильных устройствах.
Как использовать
Подчеркните mobile-first подход и попросите AI обеспечить адаптивность на всех стандартных брейкпоинтах. Укажите конкретные проблемы, если они есть.
2 Mobile-First Transformation
⌄
Prompt
Transform this desktop-only component into a mobile-first design with responsive breakpoints: [paste component]. Prioritize content and interactions for small screens first, then enhance for larger screens.
Когда использовать
Когда компонент разработан только для десктопа и нужна мобильная версия.
Как использовать
Вставьте компонент, AI переделает его с приоритетом на мобильные устройства.
